Library file

Open a dedicated Fondue library Design file.

Components are grouped by category and family, such as Buttons / Button. Enable Show subfolders in Assets to browse these folders.

Organize applies category folders to existing components and preserves styling, content and other library edits.

Import and Update first save a recovery version. If interrupted, close the plugin and restore the matching “Before Fondue” version in Figma’s Version History. Restoring affects the whole file, including later edits by collaborators.

Compose with slots

Adds editable components using existing library variables, styles and linked parts. Existing components and their local changes are reused. A recovery version is saved first.

Select a control, row or cell on the canvas. These actions edit its contents.

Resize a cell, then use Match column width to apply that width to its column. Insert actions require the editable components to be installed in this library.
