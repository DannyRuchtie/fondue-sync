# Fondue Sync checkpoint — 2 November 2026

## Implemented in this checkpoint

- Shared component category mapping, category-based Figma asset names and gallery organization. Existing managed component identities are preserved; a separate Organize action handles names without replacing locally edited content.
- Product patterns reference canonical base controls, with build-time composition auditing and guarded migrations for managed primitive layers.
- Import, Update and Organize wait for an acknowledged Figma version-history checkpoint. Recovery is manual through Version History.
- Plugin and upstream Fondue update notices, with bounded network checks.
- Dynamic-page-compatible plugin event subscriptions to avoid the startup failure.
- Rebuilt release bundle, plugin output, coverage reports and regression tests.

## Verified locally

- `npm run verify`: bundle generation, TypeScript, 268 passing tests and plugin build.
- Explorer: TypeScript, production build and four shadow tests pass. Its production build reports a large JavaScript chunk.
- Local tests establish renderer/model behavior; they do not establish native Figma restoration or published consumer behavior.

## Native and release acceptance still open

- Test complete checkpoint restoration in a disposable Figma file, including variables, styles, metadata, identities and overrides.
- Review library changes and verify a consuming instance receives updates before broad publication.
- This Git checkpoint does not publish a Figma library, create a GitHub release or deploy the explorer.

## Composition registry proposal — not implemented

The proposed repository-backed registry and editable overview remain future work. They should reconcile source components, sync definitions and observed Figma assets, flag missing configuration, and support planned components. Runtime Figma status must be obtained from a fresh scan rather than inferred from bundled coverage.

The inspected SegmentedControl is currently a linked instance with two fixed item frames and no segment-count property. The recipe likewise generates two items. Arbitrary item composition, a reusable Item component and five-segment configuration are not implemented by this checkpoint.

The intended next step is to inventory component composition requirements and define shared defaults, reusable parts, editable/repeatable regions and generator capability status before adding the editor.
