# Real media fixtures

Six user-selected images from the Frontify media library are committed for private, offline design examples. Source asset IDs, names, canonical links, intended crops and digests are in [manifest.json](manifest.json).

The downloaded WebP renditions were converted to JPEG quality95 with their original dimensions, because the Figma decoder requires PNG/JPEG/GIF. The committed JPEG bytes are the native fixture authority; no runtime URL fetch or expiring link is required. Text, actors, counts and other example data remain fictional.

Use is authorized for these internal examples. Source/photographer labels do not establish a separate redistribution license; no external publication or sharing is implied.
